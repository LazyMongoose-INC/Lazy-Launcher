# Анализ эталонного запуска Minecraft 1.12.2

Дата анализа: 19 ноября 2026 года

Источник: `Launcher.log` в репозитории, commit `2538140ba451601edb204d3491edd39f50187481`.
Blob SHA: `eb640f019cef0b07b23a8e46233953f01bcad2ea`.
Размер: 7 378 526 байт; 43 604 строки.

## Подтверждено журналом

- Minecraft: `1.12.2` (строка запуска integrated server сообщает версию 1.12.2).
- Forge: `14.23.5.2860` (идентификатор сборки присутствует в стеке Forge).
- Java: `1.8.0_202` (версия видна в Java stack frames). Это подтверждает Java 8 update 202, но не показывает путь к java.exe и не доказывает разрядность JVM.
- Используется legacy Forge/FML и LaunchWrapper: в стеке присутствуют `net.minecraft.launchwrapper.Launch.launch` и `Launch.main`.
- Игра успешно дошла до одиночного мира; в ранее выполненном подсчёте журнала зафиксирована загрузка 180 модов.
- В конце файла есть запись о попытке открыть `%APPDATA%\\.tlauncher\\logs\\launcher.log`. Это запись внутри того же предоставленного файла, а не содержимое второго файла.

## Что журнал НЕ раскрывает

В нём не найдены достоверные данные для восстановления точной команды запуска:
- полный путь к исполняемому файлу Java;
- JVM arguments;
- полный classpath и порядок JAR-библиотек;
- точные аргументы LaunchWrapper / game arguments;
- значения game directory, assets directory, asset index и natives path;
- полный перечень предварительных загрузок, проверок и распаковок, выполненных лаунчером до старта процесса.

Стек вызовов LaunchWrapper доказывает способ входа в игру, но не заменяет командную строку процесса.

## Наблюдаемые ошибки

В журнале есть повторяющиеся ошибки загрузки текстур TextureFix и ошибки отдельных модов/GUI. Они не блокируют достижение одиночного мира в этой сессии. Их нельзя трактовать как причину сбоя запуска лаунчера.

## Вывод для реализации Lazy Launcher

Нельзя корректно написать точный Forge launcher command только по этому игровому журналу. Подтверждённая целевая связка для дальнейшей проверки: Minecraft 1.12.2 + Forge 14.23.5.2860 + Java 8u202 + LaunchWrapper.

Следующий технический входной артефакт — установленный version JSON для этого Forge-профиля (файл из каталога `versions/<имя-профиля>/<имя-профиля>.json`) и связанные с ним JSON-файлы наследуемых версий, если они есть. В них находятся metadata main class, libraries, rules, minecraftArguments и/или аргументы новой схемы. По ним можно восстановить classpath и шаблон запуска без догадок. Для подтверждения точного набора модов и конфигураций отдельно понадобятся файлы/манифест модпака.
