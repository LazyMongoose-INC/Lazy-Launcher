- На строке 37893 Forge сообщает: `Forge Mod Loader has successfully loaded 180 mods`.
- На строке 42577 Forge отправляет handshake: `Client attempting to join with 180 mods`, после чего перечисляет mod id и версии. Полный список вынесен в [MODPACK_INVENTORY.md](MODPACK_INVENTORY.md).

- Integrated server для Minecraft 1.12.2 запускается дважды (строки 37964 и 40347), затем останавливается и сохраняет миры. Это подтверждает фактический вход в одиночный мир и последующее сохранение.

## Что журнал не раскрывает

По этому файлу нельзя достоверно восстановить точную команду запуска:

- абсолютный путь к `java.exe`;
- JVM arguments (включая Xms/Xmx);
- полный classpath и порядок JAR-библиотек;
- точный main class и полный набор аргументов процесса;
- точные значения game directory, assets directory, asset index и natives path;
- какие библиотеки/ресурсы скачивал лаунчер, откуда и в какой последовательности;
- установочный алгоритм, проверку целостности и процедуру подготовки Forge.

В логе нет строк с `-cp`, `--tweakClass`, `--gameDir`, `--assetsDir`, `--assetIndex`, `minecraftArguments` или командной строкой Java. Наличие LaunchWrapper в стеке доказывает runtime-механизм, но не даёт его точной конфигурации.

## Ошибки и предупреждения, которые нельзя игнорировать при проверке сборки

- Много повторяющихся `FileNotFoundException` из TextureFix для ресурсов CTM и отдельных текстур Thaumcraft. Игра продолжила загрузку и дошла до одиночного мира, поэтому эти записи сами по себе не означают фатальный отказ запуска. Но соответствующие ресурсы нужно сверить с исходным паком.
- Есть parsing errors встроенных advancement Farmer's Delight.
- Есть сообщения ProjectE о не найденных fluid names и EMC exploit warnings.
- Есть предупреждение GameSettings: `Skipping bad option: lastServer:`.
- Эти записи следует классифицировать по влиянию и сверить с чистой копией сборки. Не следует массово подавлять их или считать каждую ошибку блокирующей.

## Следующие необходимые исходные артефакты

Чтобы реализовать воспроизводимую установку и точный запуск, нужны:

1. Forge version JSON из `versions/<forge-profile>/<forge-profile>.json`.
2. JSON родительских версий, если используется `inheritsFrom`.
3. Фактический каталог `mods/` с JAR-файлами (или архив сборки), чтобы сопоставить все 180 записей с файлами, версиями и хешами.
4. Каталоги `config/`, `scripts/`, `resources/`, `resourcepacks/` и остальные дополнительные файлы, если они используются.
5. Список/архив файлов `libraries/` либо возможность скачать их по стандартным Maven coordinates из metadata.
6. Сведения об источниках и лицензиях сторонних модов для определения, какие файлы можно распространять, а какие должны устанавливаться из пользовательских файлов или официальных источников.

Version JSON позволит получить main class, libraries, rules, legacy `minecraftArguments` или новую схему arguments. Он не заменяет сами моды и конфигурации сборки.

## Ограничения достоверности

Этот документ основан на полном содержимом одного Git blob `Launcher.log`. Он не утверждает, что Lazy Launcher уже реализует установку или запуск. Наличие 180 mod id в handshake не доказывает, что JAR-файлы доступны в репозитории или могут свободно распространяться.
